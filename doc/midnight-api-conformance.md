# Midnight API conformance

The reference is [midnight-integration PR #127](https://github.com/sig-net/midnight-integration/pull/127) at **`5caf03623a1a5055b884f594e297076de689be2a`**, with `@sig-net/*` packages pinned to `0.24.0-rc.3`. This matrix covers the MPC's supported Midnight → EVM type-2 → Midnight interface. It does not claim that running the MPC suite runs every test in the upstream repository.

The owning contracts are the pinned [protocol README](https://github.com/sig-net/midnight-integration/blob/5caf03623a1a5055b884f594e297076de689be2a/README.md), [Compact interface](https://github.com/sig-net/midnight-integration/blob/5caf03623a1a5055b884f594e297076de689be2a/packages/signet-midnight/src/Signet.compact), and [ABI/response serializer](https://github.com/sig-net/midnight-integration/blob/5caf03623a1a5055b884f594e297076de689be2a/packages/signet-midnight/src/abi-serde.ts).

**Configured-cache publication remains an accepted behavioral deviation.** Its tests characterize best-effort publication rather than conformance to the upstream cache guarantee. `Unviable` issuance covers an observed, different watched transaction consuming the same nonce; a consumed nonce without an observed replacement and its inclusion height still remains pending. The rows below distinguish these cases and identify the test layer establishing each property; golden coverage is not described as live-chain coverage.

The request fixture labels its transaction oracle. Eight vectors use the SDK transaction producer and ethers serialization directly. The full-width nonce case uses SDK field assembly plus ethers RLP with the exact integer, because the SDK transaction helper converts the nonce to a JavaScript number and cannot serialize `u64::MAX` safely. That case tests the Compact-declared integer encoding, not support for that value in the SDK's numeric transaction helper.

## Run the coverage

Build the pinned Compact caller and TypeScript publisher, then run the existing library suites and the explicitly ignored seam/live tests:

```sh
just build midnight
cargo test --locked -p mpc-chain-midnight -p mpc-chain-ethereum -p mpc-compact-hashing -p mpc-primitives -p mpc-node
cargo test --locked -p mpc-chain-midnight --features sandbox --lib output_storage::tests
just test-midnight-seam
just test-midnight
```

`just test-midnight` also builds the Solidity targets and starts fresh local Midnight, Ethereum, and MPC services. It includes both conformance assertions and the explicitly labeled cache-deviation characterization above. It does not establish the configured-cache guarantee or historical replacement detection. On systems with short Unix socket path limits, give the TypeScript driver a short process-scoped `TMPDIR`.
